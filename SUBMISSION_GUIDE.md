## Troubleshooting

**Problem**: "File not found" error in R
- **Solution**: Check that `paydata2017.txt` is in the same directory as the R script

**Problem**: LaTeX won't compile
- **Solution**: Ensure all required packages are installed. On Ubuntu/Debian:
  ```bash
  sudo apt-get install texlive-full
  ```

**Problem**: Plots don't show the data well
- **Solution**: The PDFs are created automatically. If you want to view interactively, comment out `pdf()` and `dev.off()` lines
